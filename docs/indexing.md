# Индексация сайта

Основной адрес — `https://kv-tyumen.ru/`. Traefik передаёт оба домена и оба протокола приложению. `App\Classes\NormalizePublicUrl` объединяет смену зеркала, нижний регистр и нормализацию слешей в один 301. Параметры запроса сохраняются побайтно. Для файлов и служебных путей регистр не меняется; POST и AJAX проходят без SEO-перенаправления. Зеркала статических файлов обрабатывает Nginx.

В Traefik отключена предварительная очистка пути, чтобы приложение могло обнаружить лишние слеши и вернуть 301. Маршрутизация Traefik основана только на домене; нормализация пути перед файловым доступом и запреты служебных каталогов остаются в Nginx. Не добавляйте авторизацию по ненормализованному префиксу пути на уровне прокси.

Canonical формируется в `layouts/default.htm` и выводится один раз через `partials/site/seo.htm`. В редакторе CMS: **страница → Настройки → SEO** доступны:

- **Canonical (необязательно)** — путь или адрес другой индексируемой страницы сайта. По умолчанию используется собственный URL без параметров. Внешние, отсутствующие и закрытые от индексации адреса игнорируются. Переопределения с цепочками canonical не принимаются.
- **Запретить индексацию** — добавляет `noindex, follow`, убирает canonical и исключает страницу из карты.

`/sitemap.xml` — маршрут приложения, а не файл. Он заново читает страницы активной темы и опубликованные записи Tailor при каждом запросе. Скрытые страницы, noindex, служебные пути и документы с canonical на другой URL исключаются. `/sitemap-store.xml` перенаправляется на единственную карту. В XML нет `lastmod`.

Обычные CMS-страницы добавляются автоматически. Динамические страницы со стандартным компонентом `[section article]`, `handle`, `identifier` и `value = "{{ :slug }}"` также обнаруживаются автоматически. Для собственной PHP-загрузки записей используются настройки страницы, как у `case-study.htm`:

```ini
sitemap_section = "Site\\CaseStudy"
sitemap_identifier = "slug"
sitemap_parameter = "slug"
```

При добавлении другого типа динамических страниц нужно указать его Tailor-раздел и параметр маршрута. Публикация проектов и sitemap используют один запрос, исключающий черновики, выключенные, удалённые, будущие и просроченные записи. Для собственного PHP-редиректа или специальной страницы задайте запрет индексации в настройках страницы. После добавления маршрутов проверяйте карту HTTP-проверкой ниже: она выявляет ошибки рендера и перенаправления в любом пользовательском PHP-коде.

Проверки:

```sh
# Только чтение: все URL карты, canonical, robots, 404, зеркала, параметры и файлы.
python3 scripts/check-indexing.py

# Только локальный Docker: временная CMS-страница и изменения записей с rollback.
docker compose exec -T -e KV_INDEXING_LOCAL_TEST=1 app php < scripts/test-indexing-cms.php
```

`check-indexing.py --local-edge` проверяет те же публичные домены через изолированный локальный Traefik на портах 18080 (HTTP) и 18443 (HTTPS). Только этот режим допускает самоподписанный тестовый TLS-сертификат.

При публикации изменений нужны очистка кэшей October и маршрутов, пересоздание Nginx для новых Docker labels и перезапуск Traefik для настроек entryPoints. Не пересоздавайте базу данных и не заменяйте `traefik/acme.json`.
